❓ Bantuan Lengkap

Panduan penggunaan Cacti AutoData Web Dashboard

Selamat datang di Cacti AutoData! 🌵

Aplikasi ini mengotomatisasi perekaman data bandwidth (Traffic In/Out) dari server Cacti ke file Excel ataupun Google Forms.


Keunggulan Utama:

  • 🔑 Cookie Auth — Menggunakan sesi login browser Anda, tidak perlu simpan password
  • 📊 Mode Excel — Otomatis isi template Excel perusahaan dengan nilai Current, Average, Max
  • 📤 Mode Google Form — Upload data peak 24-jam penuh ke formulir evaluasi kapasitas
  • 🧪 Dry Run & Demo — Test tanpa risiko mengubah data

Fungsi: Mengambil data bandwidth pada jam tertentu (09:00 & 16:00) untuk ditulis ke Excel.


Langkah-langkah:

  1. Pilih Tanggal Mulai dan Tanggal Akhir menggunakan date picker.
  2. Tentukan file Excel (opsional — biarkan kosong untuk auto-generate).
  3. Centang Sheet mana saja yang ingin diproses di bagian Sheet Selection.
  4. Klik 🚀 Mulai Rekap. Data akan ditarik dari Cacti dan ditampilkan di tab Preview.

Opsi Tambahan:

  • Skip baris terisi — Melewati baris yang sudah ada datanya di Excel
  • Skip weekend — Lewati hari Sabtu & Minggu
  • Skip hari libur — Lewati tanggal merah & cuti bersama
  • Include Metadata — Tambahkan sheet info di Excel
  • Dry Run — Simulasi tanpa menulis Excel
  • Demo Mode — Gunakan data dummy, tidak perlu koneksi Cacti

Cookie Browser: Login ke Cacti di Chrome, lalu copy cookie melalui DevTools:

  1. Tekan F12 → tab Application → Cookies
  2. Cari cookie bernama Cacti atau PHPSESSID
  3. Klik 2x pada Value → Copy → Paste di Settings

URL Cacti: Alamat root/graph utama dari Cacti monitoring.

Format Waktu: Sesuaikan dengan format komputer kantor (Titik vs Titik Dua).

Mapping Interface: Hubungkan interface Cacti ke nama sheet di template Excel.

Setelah scraping selesai, data hasil ditampilkan per Sheet/ISP dalam tabel.

  • Klik tab sheet di atas tabel untuk melihat data per interface
  • Kolom Status menunjukkan apakah data akan menjadi baris baru atau update baris lama
  • Klik "Tulis ke Excel" untuk menyimpan data ke file
  • File output tersimpan di folder result/

Fungsi: Upload data kapasitas peak harian ke Google Form secara otomatis.


Perbedaan dengan Excel Mode: Fitur ini independen dari Excel! Ia mendownload data CSV 00:00–23:59 untuk menemukan peak absolut.


Langkah:

  1. Masukkan URL Google Form (harus akses publik!)
  2. Klik "Auto Detect IDs" untuk mengisi entry ID otomatis
  3. Tentukan rentang tanggal dan klik "Tarik Data & Preview"
  4. Hilangkan centang hari yang ingin di-skip
  5. Klik "Upload ke Google Form" dan pantau log status

Q: "Cookie tidak valid / Sesi habis"

A: Buka Cacti di Chrome → pastikan sudah login → F12 → Network → copy Cookie header → paste di Settings.


Q: Google Form HTTP Error 401?

A: Pastikan opsi "Batasi untuk organisasi" di-MATIKAN pada setting Google Form.


Q: "Permission Error / File Access Denied"

A: Tutup file Excel di Microsoft Office → klik Retry di dashboard.


Q: Tidak ada data diambil?

A: Pastikan cookie valid, URL benar, dan server Cacti bisa diakses. Coba Demo Mode untuk testing.

🔑 Cara Mendapatkan Cookie Cacti
  1. Buka Cacti di browser Chrome/Edge dan pastikan sudah login
  2. Tekan F12 untuk membuka Developer Tools
  3. Klik tab Application (Chrome) atau Storage (Firefox)
  4. Di panel kiri, buka Cookies → klik URL Cacti Anda
  5. Cari cookie bernama "Cacti" atau "PHPSESSID"
  6. Klik 2x pada kolom Value → Ctrl+C untuk meng-copy
  7. Kembali ke sini, paste di field Cookie Value

💡 Tips: Cookie biasanya berupa string panjang acak seperti a5b3c7d9e1f2.... Cookie akan expire jika session habis — ulangi langkah ini jika muncul error "Sesi habis".
